# 主题切换动画修复（2026-11-11）

重复从暗色切到亮色时，页面背景可能先变亮，再播放圆形揭示动画。

本地浏览器诊断确认：`Element.animate()` 创建的 `::view-transition-old(root)` / `::view-transition-new(root)` 动画使用 `fill: both`，在 View Transition 完成后仍以 `finished` 状态保留裁剪效果。下一轮快照会再次受到这些效果影响。

修复跟踪当前圆形动画，在过渡完成、被新切换打断、无动画切换或组件卸载时取消；每轮完成回调仅清理自己创建的动画，避免迟到的回调取消新一轮动画。保留原有 500ms 圆形过渡和减少动态效果的降级路径。

文字开关改为 SVG 图标：亮色时显示月亮（切换到暗色），暗色时显示太阳（切换到亮色）。保留中文无障碍名称、键盘操作与焦点轮廓，清除原文字指示条样式。

验证：

- 新增 5 项实际组件脚本回归测试；修复前 4 项失败，修复后通过。覆盖多轮切换、快速打断、卸载、非动画更新、捕获前取消与减少动态效果/不支持 API 的浏览器。
- 全量 48 项测试通过，Astro/Svelte 检查、生产构建及 290 个本地链接验证通过。
- 浏览器诊断确认结束后不再残留圆形快照动画；完成连续 6 次切换、390px 手机布局及 Enter 键操作验证。
- 诊断输出仅用于本地排查，未包含在发布源码中。
