# 主题与素材来源

当前使用 [Kanade 官方主题目录](https://astro.build/themes/details/kanade/) 指向的 [sudoriaa/Kanade-Astro 模板分支](https://github.com/sudoriaa/Kanade-Astro/tree/codex/astro-theme)，固定版本 `d5ea45630603305e48682943ee7e8a0569400386`。

导入其布局、组件、样式、花朵头像、首屏插画和本地字体。上游 README 的原始素材说明保存在 `docs/upstream/kanade-readme.md`。没有导入作者个人照片、演示文章和展示截图。

该模板版本未附独立 LICENSE 文件；这里记录来源和署名，不为第三方代码或素材重新声明授权。字体「造字工房悦圆」及「Oxanium」、首屏插画均沿用上游资源及原始署名。图标通过各自的 `@iconify-json/*` 包提供，许可随依赖发布。

圆形明暗动画从此前的 Pudding 实现迁移，并保留动画清理修复。Pudding 的 MIT 许可见 `docs/LICENSE-Pudding`，更早的 AstroPaper 许可见 `docs/LICENSE-AstroPaper`。
