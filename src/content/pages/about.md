你好，我是 **HeliumBoom**。

欢迎来到我的个人主页与技术博客。这里是一个安静的记录空间，用来整理技术探索、开发实践，以及解决问题时留下的思考。

## 在这里读到什么

- **技术笔记**：从一个具体问题出发，记录理解它、验证它、解决它的过程。
- **开发实践**：工具的使用方式、实现中的取舍，以及可以再次用上的经验。
- **学习与思考**：把零散的发现整理成文章，让知识有迹可循。

这个站点刚刚起步，内容会随着新的实践逐步积累。

## 找到我

- [GitHub · HeliumBoom](https://github.com/HeliumBoom)
- [RSS 订阅](/rss.xml)：通过阅读器获取新文章。

## 关于本站

本站使用 [Astro](https://astro.build/) 构建，基于 [AstroPaper](https://github.com/satnaing/astro-paper) 主题定制，托管于 GitHub Pages。

用 Markdown 写作，用 Git 管理，让注意力更多地留在内容上。
